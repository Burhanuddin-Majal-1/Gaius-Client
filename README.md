# Gaius Client
## An Unofficial Minecraft Client Replica

# How to Use
## Step 1
Open a Brand New Codespace and type this in the terminal
```cd Network/Runtime/Paper && java -Xms1G -Xmx2G -jar paper.jar --nogui```

## Step 2
Open another Tab and paste this in the Terminal
```cd Network/Runtime/Velocity && java -Xms512M -Xmx1G -jar velocity.jar```

## Step 3
Allocate 3 Ports For The Client to function Properly.

- 8081
- 8080
- 26656

# Done,
